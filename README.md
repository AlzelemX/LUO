# LUO

Telegram Mini App: محفظة TON غير احتجازية + لعبة جواهر وقنابل + لوحة تحكم لصاحب البوت.

الرابط: https://luo-bice.vercel.app

## البنية

**الواجهة** (ملفات ثابتة على Vercel، تنتشر تلقائيًا مع كل push على `main`):

- `index.html` / `style.css` — الصفحات والتصميم
- `config.js` — عنوان السيرفر فقط
- `api.js` — الاتصال بالسيرفر وأدوات مشتركة
- `app.js` / `lib.js` — المحفظة (TON Connect): الأرصدة، الاستقبال، الإرسال، الدفع
- `game.js` — اللعبة، بطاقات الإعلانات، وضع التجربة
- `admin.js` — لوحة صاحب البوت
- `vendor/` — مكتبات مثبتة الإصدار: `@tonconnect/ui` 5.0.1، `tonweb` 0.0.66، `qrcode-generator` 2.0.4

**السيرفر** (Supabase، مشروع `luo`):

- `supabase/functions/api/index.ts` — دالة واحدة لكل الأوامر (منشورة باسم `api`)
- قاعدة البيانات: `players`، `rounds`، `settings`، `announcements`، `announcement_claims`، `balance_log`، `private_config`.
  كل الجداول عليها RLS بدون policies، فما يوصلها إلا السيرفر.

## كيف تشتغل

- هوية اللاعب تثبت من `initData` حق تلقرام (موقّع بتوكن البوت)، والسيرفر يتحقق من التوقيع في كل طلب.
- الجولات الحقيقية تنحسب في السيرفر: أماكن القنابل وقيم الجواهر ما توصل للجوال إلا بعد فتح المربع أو نهاية الجولة.
- الجولة المدفوعة: السيرفر يعطي كود دفع خاص بالجولة، اللاعب يدفع من محفظته والكود في تعليق التحويل، والسيرفر يتأكد من وصول الدفعة على الشبكة (tonapi.io) قبل ما يفعّل الجولة.
- الرصيد نقاط داخل اللعبة فقط، وكل تغيير فيه مسجّل في `balance_log`.
- جولة التجربة محلية بالكامل وما لها أي أثر.

## أسرار السيرفر (Supabase → Edge Functions → Secrets)

- `BOT_TOKEN` — توكن البوت من BotFather (مطلوب)
- `TONAPI_KEY` — مفتاح tonapi.io (اختياري، يرفع حد الطلبات)

صاحب البوت يتحدد في جدول `private_config`: `admin_usernames` (يوزر، يتحول تلقائيًا لرقم ثابت عند أول دخول) و `admin_ids`.
