# LUO

Telegram Mini App — محفظة عملات رقمية غير احتجازية على شبكة TON.
المستخدم يربط محفظته عبر TON Connect؛ المفاتيح والأموال تبقى عنده، والتطبيق ما يحتفظ بأي شي.

الرابط: https://luo-bice.vercel.app

## الملفات

- `index.html` / `style.css` — الواجهة (تتبع ثيم تلقرام)
- `app.js` — الواجهة وربط المحفظة والأرصدة (قائمة العملات في مصفوفة `COINS`)
- `config.js` — إعدادات صاحب البوت: سعر الجولة (`price`) وعنوان استقبال الدفعات (`payTo`). إذا `payTo` فاضي اللعبة مجانية
- `lib.js` — منطق المبالغ والعناوين وبناء رسائل التحويل
- `game.js` — التنقل السفلي ولعبة الجواهر والقنابل (5×5، خمس قنابل، توزيع عشوائي كل جولة)
  - عند الفوز (فتح كل الجواهر) يُضاف مجموعها لرصيد نقاط محفوظ في Telegram CloudStorage. الرصيد نقاط فقط، بلا قيمة مالية، ومخزّن من جهة المستخدم.
- `tonconnect-manifest.json` — تعريف التطبيق للمحافظ (لازم يتحدث إذا تغيّر الدومين)
- `vendor/` — مكتبات مثبتة الإصدار: `@tonconnect/ui` 5.0.1، `tonweb` 0.0.66، `qrcode-generator` 2.0.4

الأرصدة تُقرأ من tonapi.io (واجهة عامة بدون مفتاح، عليها حد للطلبات).

## التشغيل محليًا

```bash
python3 -m http.server 8080
```
